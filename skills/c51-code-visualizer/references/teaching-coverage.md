# 教学覆盖、自动加页与可复用提示词

生成教学图和制图提示词时使用本文件。目标是让初学者看图读懂代码如何驱动电路；源码展示、语句解释、电路解释分别检查。用户只要代码解析时不扩展为生图，只给代码未给电路时不编造接线。

## 先建立教学覆盖表

以程序中的实际语义单元填写表格，可保存为 `teaching-coverage.md` 或同等结构的JSON；不需要空白模板或与程序无关的类别。表格规划后随制作更新，最终记录实际图片文件名与图中位置，而不是只有“已覆盖”勾选。

| 字段 | 要记录的内容 |
| --- | --- |
| 源码依据 | 行号范围、关键原句；一行多语句时分别列出作用 |
| 学生要理解什么 | 语法/数据类型、变量职责、执行条件、运算和数值含义 |
| 为什么这样写 | 该语句对输入、输出、时序或后续执行的作用 |
| 电路与状态 | 实际引脚/网络/器件、电平、数值变化或保持关系；纯软件内容可写执行状态 |
| 图片落点 | 图片文件名与卡片/表格/局部图位置；合并讲解标明共用模式及差异表 |

独立花括号、空行、纯说明注释可归属对应代码块，不必每行单设卡片。对有执行或数据含义的单元，不能以“源码页里已经有这一行”作为解释完成的理由。

## 按实际程序覆盖内容

- **声明与数据**：头文件提供什么定义，`sbit`/宏绑定什么引脚，变量存什么，`code`等限定符的用途，数组下标与表值如何对应。只解释实际用到且影响理解的概念。
- **初始化**：每次赋值或控制位操作的对象、初值、电路效果以及执行先后；说明为什么要先置位、再读或再锁存。
- **循环与采样**：循环范围、读引脚与变量赋值、延时或确认、有没有比较前后采样、有没有等待释放；画出真实返回位置。
- **分支与输出**：完整拆解代表性分支中的每条操作，用表格覆盖其余匹配条件、数据与输出差异；解释未匹配路径、break、return或阻塞对后续执行的影响。
- **函数与时序**：调用点、参数、函数体、空语句、循环次数及返回/不返回。没有时间换算依据时不将参数写成毫秒。
- **原理图对应**：引脚到网络、器件输入与输出、控制信号、有效电平、数据位序。按实际连接推导显示或动作，必要时给出状态表、时序示意或代表性输入的完整路径。
- **整体运行与问题**：最后串起正常工作过程，再单列源码/接线不一致和条件限制。纠错页不能承担本应在逐段解析页完成的全部讲解。

重复结构的讲解可以复用，但差异不能消失。例如 `P0=disp[n]; dula=1; dula=0;` 需要解释数组取值、共享总线上的数据、LE高时传送及LE低时保持，还要指出位选锁存值是否变化；仅写“显示编号”缺少中间原理。这只是锁存显示程序的示例，不预设其他程序也使用P0、同样的使能极性或位序。

## 用讲解容量决定图片数量

先定教学主题，再安排图片。对代码与电路较多的程序，可按“声明与引脚、数据/码表、初始化、采样、分支、器件工作原理、整体流程”等主题拆图；这些是可合并或继续拆分的主题，不是固定张数或必须照搬的目录。

- 同页源码和解释可读时优先相邻，引用行号建立对应。
- 必须整页展示长行源码时，另加相应逐段解析图；整套总张数 = 源码图 + 实际需要的解析图，允许增加。
- 同页知识点过多或必须缩小字号才能放下时拆图。每页3～6个相关知识点只是容量参考，不能用来截掉剩余知识点。
- 源码完整页、总流程页、输出结果页都不能单独证明语句已经讲清。解释须出现在交付的PNG中，随附说明文件只是补充。
- 用户未指定硬性张数时，简要说明页数安排后直接生成；用户硬性限制张数且无法兼顾内容时，说明冲突并给出具体拆分选择。

## 可复用提示词

下列提示词可直接用于本技能；执行时结合实际输入填写内容，不将提示词本身当成已完成的教学图：

> 请根据我提供的完整C51代码及原理图，为高职《单片机应用技术》初学者制作中文教学信息图。以讲清代码和电路为目标，先按实际逻辑拆分教学单元，建立“源码行号—解释内容—电路对应—图片位置”的覆盖表，再根据内容和课堂可读性自动决定图片张数。允许适当增加解析图，不要为了控制张数省略代码解释。
>
> 完整源码按原始行序保留，关键语句在解析页引用时标注行号。每个教学单元说明“语句及语法含义—为什么这样写—数据/电平如何变化—电路怎样动作”。覆盖程序实际出现的头文件与引脚定义、变量和数据类型、数组/码表、初始化、输入检测、判断分支、输出控制、循环阻塞和函数调用；同一行的多条语句也需解释。重复分支可完整讲一个，再用对照表覆盖其余条件和结果。
>
> 结合原理图说明实际引脚、网络与器件的关系，解释有效电平、位序、数据通路、控制时序和状态保持。程序意图与实际接线不一致时分别展示，并在源码区之外说明问题，不修改原码；缺失的电路条件标明假设。不要只展示代码、复述注释、画总流程，或只讲错误而遗漏正常工作原理。
>
> 图片采用1814×867、横向白底、清晰中文与代码字体。可以使用“完整源码页＋带源码摘录的逐段解析页＋原理图/运行过程页”，具体主题和页数以本次内容为准。代码必须程序化渲染，再与教学图形合成；放不下时加页，不缩小字体硬塞。交付前分别核验源码无遗漏、教学覆盖无遗漏、电路逻辑与接线一致，并逐张检查最终图片。交付图片、页序说明、源码基准、教学覆盖表和核验清单；截图转录与编译/仿真情况如实注明。

## 交付前的实质检查

顺着覆盖表逐项打开PNG，确认对应位置能读到该语句的含义和效果，并能沿引用回到源码。特别检查：未解释的声明/函数、同一长行中被忽略的操作、重复分支的差异、default/回路去向、位序和有效电平、锁存/驱动状态变化。若出现缺口，补图或补充现有解析图，不能用源码哈希、覆盖表勾选或一句“见代码”代替讲解。
